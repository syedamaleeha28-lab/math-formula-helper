Math Formula Helper - Icons
============================

This folder contains the extension icons:

  icon16.png  - 16x16 toolbar icon
  icon48.png  - 48x48 management page icon
  icon128.png - 128x128 Chrome Web Store listing icon

Icons feature a purple (#8B5CF6) circle on a transparent background.

To replace with custom icons:
1. Create PNG files at 16x16, 48x48, and 128x128 pixels.
2. Keep the same filenames.
3. Reload the extension in chrome://extensions.
